# SimpleMesh.AI - AI-Powered 3D Model Generation Platform
## Thesis Project - Web Application Development

**Deployed Application**: [simplemesh.ai](https://simplemesh.ai)  
*Note: Create an account to receive free credits for testing all features*

## Core Application Features

### Primary 3D Generation Services
- **[Image to 3D](https://simplemesh.ai/dashboard/image-3d)** - AI-powered conversion of 2D images to 3D models
- **[Text to 3D](https://simplemesh.ai/dashboard/text-3d)** - Natural language processing for 3D model generation
- **[Retexture Feature](https://simplemesh.ai/dashboard/retexture)** - Retexture for 3D Models

### Utility Tools (Free Access)
- **[Format Converter](https://simplemesh.ai/dashboard/tools-free/format-convert)** - Multi-format 3D file conversion (GLTF, GLB, OBJ, STL)
- **[Low Poly Simplifier](https://simplemesh.ai/dashboard/tools-free/low-poly)** - Mesh optimization algorithms

### User Management System
- **[User Dashboard](https://simplemesh.ai/dashboard)** - Model library and credit management
- **[Pricing System](https://simplemesh.ai/pricing)** - Credit-based monetization model
